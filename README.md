# 인덱스메모

**화면 가장자리의 업무 책갈피.** 평소엔 숨어 있다가 마우스를 화면 끝에 대면 나오는 색깔 인덱스 탭 메모입니다. 선생님을 위해 만들었습니다.

## 받기

**[최신 버전 받기 (IndexMemo.exe)](https://github.com/doedo81/indexmemo/releases/latest/download/IndexMemo.exe)** · [사용설명서](https://github.com/doedo81/indexmemo/releases/latest/download/manual.html)

1. 위 링크로 `IndexMemo.exe`를 받아 더블클릭합니다. 설치 과정은 없습니다.
2. 윈도우가 "Windows의 PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누릅니다. (개인이 만든 프로그램이라 인증서 서명이 없어서 뜨는 창입니다.)
3. 처음 켜면 **시작하기 안내**가 3단계로 알려 줍니다.

윈도우 10·11에서 동작합니다. 업무포털 기능을 쓰려면 구글 크롬이 필요합니다.

## 할 수 있는 일

- **새 공람 → 할 일.** 공람을 "몇 건"이 아니라 "뭘 언제까지"로 바꿔 줍니다. 공람 옆 ＋ 한 번이면 마감일 있는 할 일이 되고, 마감 빠른 순으로 정렬됩니다. 읽을 필요 없는 공람은 버튼 하나로 일괄처리합니다.
- **로그인이 풀리지 않습니다.** 수업을 다녀와도 업무포털 · K-에듀파인 · 나이스가 그대로 살아 있습니다.
- **조퇴 · 육아시간 신청 30초.** 나이스 복무 신청 화면을 채워 주고, 상신 버튼은 직접 누릅니다.
- **메모와 체크리스트.** 색깔 탭마다 메모 한 장. 화면을 차지하지 않습니다.
- **노션 할일 연동** (선택).

## 안심하고 쓰세요

- **서버가 없습니다.** 메모와 할 일은 이 PC에만 저장됩니다.
- **인증서 비밀번호나 로그인 정보를 저장하지 않습니다.** 로그인은 언제나 본인이 직접 합니다.
- 공람은 **목록만** 읽고 문서를 열지 않으므로 열람 기록이 남지 않습니다. 공람완료는 버튼을 눌렀을 때만 합니다.
- 복무 신청은 **상신 직전에서 멈춥니다.** 스스로 상신하지 않습니다.
- 인터넷으로 나가는 것은 **새 버전 확인**(이 저장소의 `latest.json` 읽기)과, 노션 연동을 켰을 때의 노션 요청뿐입니다.

## 업데이트

새 버전이 나오면 인덱스메모가 알려 줍니다. 설정 창의 **지금 업데이트**를 누르면 받아서 바꿔 끼웁니다. 받은 파일은 크기와 SHA-256 검증값이 맞을 때만 실행합니다. 메모와 설정은 그대로 남습니다.

## 알아 두세요

- 업무포털 화면 동작은 **충남교육청**에서 확인했습니다. 다른 시도교육청도 같은 시스템이라 될 것으로 보지만, 아직 실제로 확인하지 못했습니다. 안 되는 곳이 있으면 [Issues](https://github.com/doedo81/indexmemo/issues)에 알려 주세요.
- 개인이 만든 무료 프로그램입니다. 교육청이나 KERIS와 관계가 없으며, 학교의 정보보안 지침에 맞게 사용해 주세요.
